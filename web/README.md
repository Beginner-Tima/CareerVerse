# CareerVerse — фронт

Next.js 16 (App Router), React 19, Tailwind 4. Экраны: главная, тест, результат,
рабочая проба, каталог профессий, профиль. Интерфейс на двух языках — русском и
казахском, язык переключается на лету (`app/lib/i18n.ts`).

Общее описание проекта, архитектура и API — в [../README.md](../README.md).

## Запуск

```sh
npm install
npm run dev     # порт 3001
```

Адрес бэкенда задаётся в `.env.local`:

```sh
NEXT_PUBLIC_API_URL=http://localhost:3000/api
```

Без переменной фронт ходит на `http://localhost:3000/api` — то есть на локально
поднятый NestJS.

## Что где

| Путь | Экран |
|---|---|
| `/` | Главная: меню, цифры проекта |
| `/test` | Адаптивный разговор |
| `/result/[sessionId]` | Профессии, рынок труда, ожидание против результата |
| `/trial/[sessionId]` | Рабочая проба из двух шагов |
| `/professions` | Каталог профессий |
| `/me` | Профиль, история прохождений, вход по коду |
